One funny single-line excuse a developer gives when code breaks in
production, at most 200 characters. `LINE.txt` holds the line; `main.ts`
runs it through a table of rules (length, single line, no control
characters, no padding) and writes it to `/output/entry.txt` for the judge
to read.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
